# 산업안전사고 가상체험 4DX — v1.2 충돌 판정 수정

## 이번 수정
- 사용자 제공 `index(20261123-104346).html`을 기반으로 수정했습니다.
- 지게차가 작업자와 접촉하기 전 사고가 발생하던 **4초 자동 사고 판정**을 지게차 장면에서 제거했습니다.
- 지게차와 작업자의 **전체 사각형 중첩** 대신, 지게차 하단과 작업자 몸통의 접촉을 검사합니다.
- 지게차가 접촉하지 않으면 사고를 발생시키지 않고 배치 확인 안내를 표시합니다.

## 중요한 한계
- 2D 배경 사진에 이미 지게차가 포함되어 있다면 그 지게차는 움직이지 않습니다. 움직이는 지게차는 `assets/forklift.glb`입니다. 사진 속 지게차를 제거한 배경이 최종적으로 필요합니다.
- 충돌은 화면 좌표 기반의 근사 판정입니다. 실제 물리 충돌, 바퀴 회전, 작업자 관절 동작을 구현한 것은 아닙니다.
- 브라우저에서 실제 GLB와 함께 시각적으로 검증한 결과는 아닙니다. 충돌 지점의 미세 조정이 필요할 수 있습니다.
