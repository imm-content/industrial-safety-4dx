# 산업안전사고 가상체험 4DX — v1.3

## 변경 범위
기존 v1.2의 다섯 사고 장면 중 **지게차 충돌 판정**만 수정했습니다. 다른 사고의 모델·배치·연출은 유지했습니다.

## 지게차 장면
- 기존 작업자와 지게차 초기 배치 유지
- 지게차가 후진하며 작업자에게 접근
- 모델 전체 외곽 대신 지게차 차체의 화면상 접촉점과 작업자 몸통의 접촉을 계산
- 프레임 간 이동 구간을 세분 검사하고 최초 접촉 직전 위치에서 정지
- 접촉이 확인되지 않으면 충돌음·사고 경고를 실행하지 않음
- 사용자 조정 슬라이더는 기존 기능 유지

## 중요 한계
이 코드는 2D 사진 배경과 GLB 모델의 **화면상 접촉 근사**입니다. 실제 3D 물리 충돌 또는 픽셀 단위 외곽선 충돌을 보증하지 않습니다. 모델의 방향·형상에 따라 접촉 위치가 다르게 보일 수 있습니다. 실제 브라우저에서 모델 로딩 및 충돌 순간의 시각적 검증이 필요합니다.
