# 산업안전사고 가상체험 4DX — v1.8

## 체험 장면 (3개)
1. **개구부 추락** — 작업자가 개구부 쪽으로 이동한 뒤 지정된 위치에서 추락합니다.
2. **지게차 충돌** — 지게차가 지정된 정지선까지 후진하여 충돌 효과가 발생한 다음, 작업자가 바닥으로 쓰러집니다.
3. **전기설비 감전** — 작업자가 전기설비 쪽으로 몸을 돌려 이동합니다. 전기설비 앞의 지정된 위치에 도착한 다음 감전 효과가 발생하고 바닥으로 쓰러집니다.

기존 **선반 끼임**과 **밀폐공간 질식** 체험은 메뉴 및 실행 코드에서 제외했습니다.

## 파일 배치

다른 배경·GLB 파일이 저장소에 남아 있어도 v1.8에서는 불러오지 않습니다. 실제 파일 삭제는 GitHub에서 별도로 수행할 수 있습니다.

## v1.8 추가 수정
- 전기설비 감전: 작업자가 화면 오른쪽을 바라보던 오류를 수정했습니다. 초기 뒷모습(180°)에서 **화면 왼쪽의 전기설비를 향하도록 105°**로 방향을 돌리고, 전기설비 앞으로 이동합니다.
- 지게차 충돌: 지게차 GLB의 화면상 위치를 따라다니는 노란색 **「↙ 후진하는 지게차」** 안내 문구를 추가했습니다.
- 기존 개구부 추락, 지게차 이동 및 충돌 후 넘어짐, 전기설비 감전 후 넘어짐 동작은 유지합니다.
- 표시 문구는 후진 방향을 안내하는 시각적 라벨이며, 바퀴 회전 등 물리적 후진 애니메이션을 뜻하지는 않습니다.

## 이번 수정 사항
- 메뉴를 `① 개구부 추락`, `② 지게차 충돌`, `③ 전기설비 감전`으로 재구성했습니다.
- 전기설비 장면은 작업자가 초기 위치 `(47%, 78%)`에서 전기설비 쪽 `(30%, 74%)`으로 이동하면서 화면상 왼쪽을 향하도록 회전합니다. 도착 전에는 감전 효과가 발생하지 않습니다.
- 전기설비 도착 후 감전 효과 및 작업자 쓰러짐 동작을 추가했습니다.
- 지게차 충돌 후 작업자가 쓰러지는 동작을 추가했습니다. 지게차는 충돌 시점 위치에 정지합니다.
- 넘어짐 연출은 GLB 전체를 회전시키는 방식이며, 실제 관절·물리 시뮬레이션은 아닙니다.

## 설치
1. `industrial_safety_v1_7_index.html`을 **`index.html`**로 이름을 바꾸어 저장소 루트의 기존 파일을 교체합니다.
2. `industrial_safety_v1_7_README.md`를 **`README.md`**로 이름을 바꾸어 교체합니다.
3. GitHub Pages에서 강력 새로고침(`Ctrl+F5`) 후 세 장면을 각각 확인합니다.

## 검증 범위
JavaScript 문법 검사를 통과했습니다. 다만 실제 GitHub Pages 브라우저에서 GLB를 로딩한 후 화면상 이동·쓰러짐 위치를 검증하지 못했습니다. 위치와 방향은 첨부된 화면을 기준으로 설정한 값입니다.
