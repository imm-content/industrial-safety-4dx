# 산업안전사고 가상체험 4DX — v1.4

## 지게차 충돌 수정
- 지게차 GLB와 작업자 GLB의 화면 투영 범위를 매 이동 단계마다 검사합니다.
- 지게차가 작업자 몸통 영역과 처음 겹치기 직전의 위치에서 정지합니다.
- 시작부터 겹친 경우에는 더 이동하지 않고 충돌 처리합니다.
- 접촉하지 않았다면 사고 효과를 실행하지 않습니다.
- 다른 4개 장면은 기존 동작을 유지합니다.

## 주의
화면상 투영 영역을 이용한 보수적인 접촉 판정이므로 실제 차체가 몸에 닿기보다 약간 일찍 멈출 수 있습니다. 실제 물리 엔진을 사용한 3D 충돌은 아닙니다. 브라우저에서 실행해 보지 않은 수정본입니다.

## 설치
`index.html`, `README.md`를 저장소 루트에 업로드합니다. 기존 `assets/` 폴더는 변경하지 않습니다.
