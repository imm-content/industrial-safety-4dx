# 산업안전사고 가상체험 4DX (v0.4)

실제 산업현장 배경 PNG 5개와 GLB 6개를 사용하는 **교육용 4DX 스타일 시뮬레이션**입니다. 기존 v0.3에서 제기된 GLB 미표시, 작업자 조절 불가, 설비 배치, 이동 방향, 사고 경고음 문제를 개선하기 위한 버전입니다.

## 폴더 구조

```text
industrial-safety-4dx/
├── index.html
├── README.md
└── assets/
    ├── construction_worker.glb
    ├── lathe.glb
    ├── lathe_chuck.glb
    ├── forklift.glb
    ├── electrical-box.glb
    ├── storage-tanks.glb
    └── backgrounds/
        ├── gaegubu.png
        ├── seonban.png
        ├── jigecha.png
        ├── gamjeon.png

```

파일명은 대소문자를 구분합니다. GitHub Pages에서 `main` 브랜치 `/ (root)`로 배포합니다.

## v0.4 변경 사항

- **객체별 조절**: 왼쪽 `조정 대상`에서 작업자 / 설비·차량 / 선반 척을 선택하고 좌우·상하·크기·회전을 개별 조정할 수 있습니다. 각 장면 초기화 시 원위치로 돌아갑니다.
- **개구부**: 작업자가 개구부 중심 쪽으로 접근한 다음 축소·하강하여 추락을 표현합니다. 2D 사진에 실제 구멍 깊이가 있는 것은 아니므로 가림 효과에는 한계가 있습니다.
- **선반**: 기존 `lathe.glb` 본체와 `lathe_chuck.glb`를 모두 불러옵니다. 척은 별도 객체로 회전합니다. 두 모델의 정확한 결합 위치는 현장 화면에서 조정해야 합니다.
- **지게차**: `forklift.glb`를 로드하고 사진의 통로 방향을 따라 이동하도록 설정했습니다. **원본 지게차 모델에 바퀴 회전용 독립 메시가 확인되지 않아 바퀴 굴림은 아직 구현하지 못했습니다.**
- **감전**: 배전반을 왼쪽 노란 표시 구역에 배치하고 작업자가 접근하도록 설정했습니다.
- **질식**: 저장탱크를 노란 표시 구역에 배치하고 작업자가 탱크 쪽으로 이동하도록 설정했습니다.
- **경고음**: Web Audio 경고음을 이전보다 크게 설정하고 3회 연속 울리도록 했습니다. 실제 소리는 기기 볼륨 및 브라우저 정책의 영향을 받습니다.
- **오류 확인**: 모델 파일이 없거나 로딩에 실패하면 브라우저 콘솔과 화면 상태에 실패 메시지가 표시됩니다.

## 사용 방법

1. 왼쪽에서 다섯 사고 현장 중 하나를 선택합니다.
2. `GLB 준비 완료` 상태와 모델 표시를 확인합니다.
3. 조정 대상에서 **작업자**, **설비/차량**, **선반 척** 중 하나를 선택합니다.
4. 슬라이더로 해당 모델의 위치·크기·회전을 조정합니다.
5. `배치값 복사`로 조정값을 복사해 제작자에게 전달할 수 있습니다.
6. `사고 시뮬레이션` 버튼으로 연출을 확인합니다. `장면 초기화`로 처음부터 다시 실행합니다.

## 중요한 기술적 한계

이 콘텐츠는 **2D 사진 배경에 3D GLB를 합성**하는 방식입니다. 실제 3D 공간에서의 충돌 판정, 건설현장 바닥 구멍을 통과하는 물리 시뮬레이션, 자연스러운 인체 관절 동작, 선반 척에 옷소매가 실제로 감기는 시뮬레이션은 아직 없습니다. 특히 바퀴 회전과 작업자 관절 애니메이션을 완성하려면 원본 모델의 메시 분리·리깅 또는 추가 3D 모델링이 필요합니다. 따라서 v0.4는 **현장 배치 및 연출 검증본**이며 전자책에 실을 최종 완성본이 아닙니다.

화면 흔들림, 음향, 섬광은 4DX 스타일 효과이며 물리적 좌석 진동·바람·물 분사 기능은 지원하지 않습니다. 섬광과 진동에 민감한 사용자는 체험을 중지하십시오.

## 출처와 라이선스
