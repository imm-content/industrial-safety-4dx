# 산업안전사고 가상체험 4DX — v1.5

## ③ 지게차 충돌 장면 수정

- 사용자 첨부 화면에서 빨간 가로선의 위치를 체험 화면 기준 **가로 약 49.5%, 세로 약 81%**로 읽어 최종 정지 지점으로 지정했습니다.
- 지게차 `forklift.glb`가 후진하며 점점 커지고, **GLB의 화면상 하단이 지정 위치에 도달하면 정지**합니다.
- 중간에 발생하던 자동 충돌 감지 기능을 지게차 장면에서 사용하지 않습니다.
- 지게차가 최종 위치에 도착한 **후에만** 충돌 효과와 작업자의 기울어짐이 시작됩니다.
- 나머지 4개 장면은 변경하지 않았습니다.

## 설치

GitHub `imm-content/industrial-safety-4dx` 저장소의 루트 `index.html`을 제공된 HTML 내용으로 교체합니다. 파일 이름은 `index.html`로 바꾸세요. `README.md`도 같은 방법으로 교체합니다. 기존 `assets/` 폴더와 GLB 파일은 유지합니다.

## 검증 및 주의

이 변경은 사용자가 지정한 **화면상 빨간 선을 정지 기준**으로 하는 연출입니다. 실제 3차원 물리 충돌 계산이 아닙니다. 화면 크기와 객체 배치 슬라이더 변경 시 작업자와의 시각적 접촉은 달라질 수 있습니다. JavaScript 구문 검사를 수행했지만 실제 GitHub Pages의 GLB 렌더링 장면은 검증하지 못했습니다.


## v1.6 개구부 추락 경로 수정
- 사용자가 표시한 빨간 선 끝 원을 **개구부 추락 지점(화면 기준 x 47.85%, y 68.15%)**으로 설정했습니다.
- 기존 `hole:[55,67]` 좌표를 변경했습니다.
- 작업자의 GLB 중심이 아니라 **발끝(모델의 화면상 최하단)**을 기준으로 빨간 선을 따라 이동하도록 계산합니다.
- 4초간 이동하여 원에 도착한 뒤 추락 효과를 시작합니다.
- 지게차 및 다른 사고의 이동·효과 코드는 변경하지 않았습니다.
- 실제 브라우저에서 GLB 렌더링 동작은 검증하지 못했습니다.
