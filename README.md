# 산업안전사고 가상체험 4DX (v0.5)

GitHub Pages에서 실행하는 산업안전 사고 예방용 3D 모델·2D 현장 배경 결합 체험입니다.

## 폴더 구조

```text
industrial-safety-4dx/
├── index.html
├── README.md
└── assets/
    ├── construction_worker.glb

    ├── forklift.glb

    ├── storage-tanks.glb
    └── backgrounds/
        ├── gaegubu.png
        ├── seonban.png
        ├── jigecha.png
        ├── gamjeon.png
        └── jilsik.png
```

## v0.5 변경 사항

- 개구부 장면의 작업자 초기 위치를 개구부 바깥쪽으로 변경했습니다.
- 사고 시작 후 작업자가 개구부 중심으로 이동하고 그 자리에서 축소·하강해 사라지는 2.5D 추락 연출을 적용했습니다.
- 작업자/설비 조정 슬라이더 옆에 현재 값을 표시합니다.
- 사고 재현 중 조정 슬라이더를 움직이면 재현을 중지하고 사용자가 지정한 배치를 다시 적용하도록 수정했습니다. 이전에는 재현 루프가 사용자의 조정값을 덮어썼습니다.
- JavaScript 문법 검사를 수행했습니다.

## 조작

1. 현장을 선택합니다.
2. **조정 대상**에서 `작업자`, `설비 / 차량`, `선반 척`을 선택합니다.
3. `좌우`, `상하`, `크기`, `회전` 슬라이더를 움직입니다. 크기는 100%가 기본입니다.
4. `사고 시뮬레이션`을 클릭합니다.
5. `장면 초기화`로 초기 배치로 돌아갑니다.

## 중요 제약

- 배경은 사진이므로 실제로 뚫린 3D 개구부가 아닙니다. 현재 추락 장면은 사진 속 구멍 중심으로 작업자를 이동시키고 축소·하강시키는 **시각적 연출**입니다. 바닥 아래층까지 물리적으로 추락하거나 사진의 앞뒤 가림이 정확하게 적용되지는 않습니다.
- 작업자 GLB에 관절 애니메이션이 없어 자연스러운 보행·발 헛디딤 동작은 제공하지 않습니다.
- 사진과 GLB의 위치는 기기 화면 비율에 따라 보정이 필요할 수 있습니다. 슬라이더로 맞춘 값은 `배치값 복사`를 통해 확인할 수 있습니다.
- 이 버전은 개구부 초기 위치 및 모델 조정 문제를 우선 개선한 버전입니다. 다른 사고의 사실적 애니메이션까지 완성한 것은 아닙니다.
- 경고음은 기기 볼륨과 브라우저 정책에 영향을 받습니다.

## 배포

GitHub 저장소의 루트에 `index.html`, `README.md`를 두고 `assets` 폴더를 유지합니다. Settings → Pages → Deploy from a branch → `main` / `(root)`로 설정한 후 페이지를 열고 Ctrl+F5로 새로고침합니다.

## 라이선스

GLB 모델과 배경 이미지의 원본 라이선스를 각각 확인하고, 저작자 표시 및 재배포 조건을 준수해야 합니다.


## v0.6 지게차 충돌 장면 보정
- 작업자 초기 위치와 크기: 화면 왼쪽 전경, 크기 4.0으로 확대
- 지게차 초기 위치: 창고 통로 중앙 안쪽 (34%, 51%), 크기 2.6
- 지게차 후진: 통로 안쪽에서 작업자 방향으로 이동하면서 원근감을 위해 점진 확대
- 작업자는 충돌 전 위치를 유지합니다. 실제 바퀴 회전은 모델 부품 분리 확인 전까지 미구현입니다.
- 배경이 2D 이미지이므로 실제 물리 충돌이나 깊이 가림은 구현하지 않았습니다.
