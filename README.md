# 산업안전사고 가상체험 4DX

브라우저에서 실행하는 **산업안전 교육용 3D·4DX 스타일 가상체험**입니다. 사고 전 위험요인을 확인하고 안전 행동을 선택하면 그 결과를 시청각 시뮬레이션으로 확인할 수 있습니다.

> **주의:** 실제 4DX 영화관의 움직이는 좌석·바람·물 분사 장치는 지원하지 않습니다. 화면 움직임·경고음·시각 효과·선택형 상호작용을 활용한 웹 교육 콘텐츠입니다. 실제 현장의 안전교육이나 법정 절차를 대체하지 않습니다.

## 체험 주제

1. 건설현장 개구부 추락사고
2. 선반작업 끼임사고
3. 지게차 충돌사고
4. 전기설비 감전사고
5. 밀폐공간 질식사고

## 저장소 구성

```text
industrial-safety-4dx/
├── index.html
├── README.md
└── assets/
    ├── construction_worker.glb
    ├── lathe.glb
    ├── lathe_chuck.glb
    ├── forklift.glb
    ├── electrical-box.glb
    └── storage-tanks.glb
```

파일명은 **대소문자, 밑줄, 하이픈까지 정확히 일치**해야 합니다.

## 실행 방법

1. GitHub에서 `industrial-safety-4dx` 저장소를 만듭니다.
2. 루트에 `index.html`, `README.md`를 업로드합니다.
3. `assets` 폴더에 GLB 6개를 업로드합니다.
4. **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `/(root)`를 선택하고 저장합니다.
5. 배포가 완료되면 `https://imm-content.github.io/industrial-safety-4dx/`에서 실행합니다. (계정이 `imm-content`일 경우)

Three.js는 CDN에서 불러오므로 **인터넷 연결이 필요**합니다. `file://`로 HTML을 직접 열면 브라우저 보안 정책 때문에 모델 로딩이 실패할 수 있으므로 GitHub Pages나 로컬 웹 서버를 사용하세요.

## 조작법

- 현장 선택: 왼쪽 메뉴 또는 모바일 상단 메뉴
- 시점 회전: 마우스 드래그 / 터치 드래그
- 확대·축소: 휠 / 두 손가락 제스처
- 행동 선택: 두 가지 선택지 중 하나 클릭
- `사고 시뮬레이션`: 선택한 결과 확인
- `다시 체험`: 현재 현장 초기화
- `일시정지`: 시뮬레이션 중 일시정지/계속하기
- `R`: 현재 현장 초기화
- 화면 흔들림·섬광 효과 및 한국어 음성 안내: 체크박스로 켜기/끄기

## 구현 방식과 한계

- **작업자**: 제공된 모델에 뼈대 애니메이션이 없어 전체 이동·기울기 방식으로 표현합니다.
- **선반**: 본체 모델과 별도 척 모델을 조합하여 회전시킵니다. 척의 실제 장착 위치·회전축은 모델을 보며 보정해야 합니다.
- **지게차**: 전체 모델을 이동시킵니다. 바퀴 회전은 별도 구현하지 않았습니다.
- **배전반**: 모델을 표시하고 별도 광원으로 감전 위험을 표현합니다. 문 여닫기는 미구현입니다.
- **탱크**: 외부 모델을 표시하며 밀폐공간의 위험을 경고합니다. 내부 탐험·산소농도 센서 연동은 미구현입니다.
- 모델의 실제 배치와 방향은 원본 GLB의 축·원점에 따라 조정이 필요할 수 있습니다.
- 음성은 브라우저의 한국어 TTS 지원 여부에 따라 달라집니다.

이 버전은 **초기 통합 체험판(v0.1)**입니다. 다섯 현장의 모델 로딩, 선택 분기, 시청각 효과와 기본 예방수칙을 우선 통합한 버전이며, 사실적인 신체 동작·충돌 물리·정밀한 기계 부품 애니메이션은 후속 개선 대상입니다.
